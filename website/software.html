The software ecosystem

One connected platform, from driver to franchise

Built on the OCPP standard, so every charger — ours or a partner's — reports live status, sessions and faults back to one dashboard. OCPI and OCPP 1.6J enabled, secure API and data encryption throughout.

For drivers

  • AI-driven charger discovery & route planning
  • Real-time availability, by AC/DC or speed
  • Select multiple EVs on one account
  • Comprehensive charger filters (connector, speed)
  • Integrated with all major Indian payment gateways
  • Green kilometres travelled, tracked automatically
  • Manage tagged RFIDs

For operators & franchises

  • CMS — live stations, sessions & revenue
  • Franchise Dashboard — your stations, payouts & performance
  • Client Dashboard — real-time charger monitoring
  • Remote diagnostics & over-the-air upgrades
  • Dynamic, data-driven pricing decisions
  • OCPI + OCPP 1.6J, secure API & data encryption
